Jarvis Publicador

O Jarvis Publicador é um programa de linha de comando, de uso pessoal, que envia vídeos para os canais do YouTube do próprio autor: Código Cotidiano e Stopsizer. Ele roda no computador do autor e usa a YouTube Data API v3 para publicar vídeos, definir título, descrição, miniatura, playlist e visibilidade, e para gerenciar os comentários desses canais.

Este programa usa os Serviços de API do YouTube (YouTube API Services) e está sujeito aos Termos de Serviço do YouTube e à Política de Privacidade do Google.

Não há outros usuários além do dono dos canais. O programa não coleta dados de terceiros nem oferece serviço ao público.

Leia a Política de Privacidade e os Termos de Serviço.
